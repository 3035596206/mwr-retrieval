# 论文方法融合后的下一阶段实施计划

> 更新时间：2026-07-21  
> 项目：MWR 温湿廓线反演  
> 依据：`论文方法与当前项目融合深度调研报告.docx`、`reports/进度记录/OEM阶段进度.md`、`docs/oem_retrieval_plan.md`、`docs/brnn_oem_bridge_plan.md`

## 1. 先给结论

当前项目已经完成“能不能做 OEM”的验证，下一阶段要回答的是：

1. 论文中的多仰角观测机制，能否在当前 14 通道体系中带来稳定的近地层增益；
2. BRNN v4 的统计结果，能否在不破坏物理一致性的前提下转化为 OEM 的先验 `x_a` 和 `S_a`；
3. 云天 LWC 联合反演和 NN surrogate 是否能够形成可扩展、可校准的混合系统。

推荐的执行顺序是：

```text
物理一致性基线
    -> 虚拟多仰角机制验证
    -> S_a/S_e 与状态向量升级
    -> BRNN 先验桥接
    -> NN surrogate 加速
    -> 云天 T/RH/LWC 联合 OEM
    -> 不确定度校准
    -> DeepOE / 高频旋转硬件论证
```

不建议当前直接追求 220--600 GHz 硬件复现。论文的近地层优势同时来自高频通道、角度数量和观测配置，必须先把“多角度是否有效”和“高频是否提供不可替代的边际信息”拆开验证。

## 3. 未来 2 周：必须完成的 P0 闭环

### P0-1：冻结并扩大 MonoRTM OEM 物理基线

目标：建立论文方法融合前的可比较基线，避免后续增益无法归因。

实施：

1. 在现有 `scripts/run_oem_201301.py` 基础上固定随机种子、状态定义、`S_a`、`S_e`、收敛阈值和输出字段；
2. 扩大 2013-01 self-consistent MonoRTM 实验到 n=744，若计算成本过高先完成 n=200/500，并记录实际耗时；
3. 每个样本保存 prior/posterior profile、BT residual、cost history、AK、DOFS、posterior covariance 和迭代次数；
4. 增加失败样本清单，不能只输出成功样本的均值。

建议新增或整理：

```text
scripts/run_oem_baseline.py
scripts/evaluate_oem_batch.py
results/oem_baseline_monortm_n744/
```

验收标准：

```text
收敛率 >= 95%
无 NaN/Inf 的 posterior covariance
BT residual 平均值和分位数均有记录
T/RH prior、posterior、bias、RMSE、DOFS、AK 全部可复算
```

### P0-2：先做通道和数据资产审计

目标：决定 BRNN v4 是走“原始 MP-3000A 直接桥接”还是“14 通道重新训练/迁移”。

检查清单：

1. 搜索项目和用户数据目录中的 MP-3000A 原始 `.nc/.cdf/.mat/.pkl`；
2. 确认 22 通道中心频率、极化、单位、时间戳、缺测值和 `Obs_BT` 字段；
3. 对照 `train_mp3000a_v4.py`，确认 v4 实际输入维度、通道顺序、地面气象和 IR 特征；
4. 对照 `src/monortm_wrapper.py`，确认当前 14 通道是否硬编码，并设计自定义频率接口；
5. 输出一张“MP-3000A 22ch / HATPRO 14ch / MonoRTM 输入”的映射表。

交付物：

```text
reports/通道与观测数据审计_2026-07-21.md
config/channel_inventory.json
```

决策闸门：

```text
若拿到 MP-3000A Obs_BT + 频率表：走 22ch MonoRTM 一致性桥接；
若拿不到：停止等待数据，转入 HATPRO 14ch BRNN 或仅迁移 v4 残差统计；
禁止用通道插值结果冒充真实 MP-3000A/OEM 融合结果。
```

### P0-3：虚拟多仰角 OEM 机制试验

这是本次论文融合最优先的算法试验。目标不是复现论文的 220/600 GHz 绝对精度，而是验证“多仰角 + 角度/通道筛选”在现有频段是否有边际收益。

实施步骤：

1. 将观测向量从单一仰角扩展为 `y=[BT(channel, elevation)]`；
2. 让 `ForwardModel` 接收仰角参数，并为每个角度返回亮温；
3. 在 `S_e` 中明确角度间是否独立；若存在共同偏差，增加块相关或 bias 参数；
4. 实现论文启发的几何 QC：远离天顶、低不透明通道、水平传播距离超过阈值的组合剔除；
5. 设计 A/B/C 三组实验：
   - A：当前单仰角 14ch 基线；
   - B：14ch 多仰角，不做筛选；
   - C：14ch 多仰角 + 几何/通道筛选；
6. 重点统计 0--500 m、0--1 km 和全廓线的 T/RH 误差。

建议新增：

```text
src/oem_geometry.py
scripts/run_oem_multiview.py
results/oem_multiview_clear/
```

验收指标：

```text
近地 0--500 m 的 T RMSE、bias、剖面误差分位数
全廓线 T/RH RMSE 与 BT RMS
AK 峰值、垂直分辨率、DOFS
各仰角/通道保留率与失败样本率
```

判定规则：若 C 相对 A 在 0--500 m T 误差上没有稳定改善，或改善只来自少数异常样本，则不进入旋转硬件论证，转而优先优化 `S_a/S_e` 和状态向量。

## 4. 第 3--6 周：把论文机制变成混合反演部件

### P1-1：统一状态向量与 EOF/PCA 对照

先保留当前 14 维 `T7+RH7` 作为可解释基线，再做 10 维和 16 维 EOF 对照，不要直接上 186 维全廓线。

实验矩阵：

| 状态 | 目的 | 通过条件 |
|---|---|---|
| 14d T7+RH7 | 工程基线 | 收敛稳定，指标可复现 |
| 10d EOF | 降低病态性和 Jacobian 成本 | 不显著恶化全廓线和近地层 T |
| 16d EOF | 增加表达能力 | 相比 10d 有明确增益且仍稳定 |
| 21d T7+RH7+LWC7 | 弱云联合反演 | LWC 非负，T/RH 不发生系统性退化 |

验收不能只看总 RMSE，还要检查 EOF 截断导致的近地层信息丢失、AK 和 DOFS 变化。

### P1-2：重构 `S_a` 和 `S_e`

`S_a` 采用三层递进设计：

1. 指数相关对照：保留现有 sigma 与垂直相关长度；
2. v4 residual covariance：按 profile 分组计算 T/RH 残差协方差，做正定化、收缩和小特征值截断；
3. 场景条件协方差：晴空、弱云、逆温、极端湿层分别估计，避免一套协方差覆盖所有天气型。

`S_e` 采用：

1. 仪器噪声；
2. OMB 残差；
3. MonoRTM/surrogate 前向误差；
4. 多仰角共同偏差项；
5. 云天 K 波段膨胀或通道剔除。

验收标准：所有协方差矩阵必须对称、正定或经过明确正则化；必须报告条件数、最小特征值和正则化强度。

### P1-3：BRNN 先验桥接，分两条可执行路线

路线 A：有 MP-3000A 原始观测时。

```text
MP-3000A Obs_BT + surface features
    -> BRNN v4
    -> x_a
    -> MonoRTM 22ch H(x)
    -> OEM posterior
```

必须先完成频率、通道顺序、单位、偏差订正和 `H(x)` 一致性检查，再比较 BRNN prior 与 OEM posterior。

路线 B：仍无 MP-3000A 原始观测时。

```text
ERA5 / HATPRO 14ch MonoRTM
    -> 14ch BRNN 或残差统计迁移
    -> x_a / S_a
    -> 14ch MonoRTM OEM
```

此路线可以推进 NN/OEM 方法，但不能称为“BRNN v4 直接融合”，应在文档和论文中明确为 14ch 适配模型或统计先验迁移。

桥接实验至少包含：

1. ERA5 first guess + 固定 `S_a`；
2. BRNN/适配 BRNN first guess + 固定 `S_a`；
3. BRNN first guess + v4-derived `S_a`；
4. 先验与后验的 profile RMSE、BT residual、DOFS、posterior uncertainty 对照。

## 5. 第 2--3 个月：NN surrogate 与云天联合 OEM

### P2-1：MonoRTM residual surrogate

推荐先做残差 surrogate，而不是直接从 profile 预测 MonoRTM BT：

```text
BT_mono(profile, geometry)
    ~= BT_simple(profile, geometry) + NN_residual(profile, geometry)
```

训练数据来自 MonoRTM 与 simple RTM 的成对正演结果。输入至少包含：

```text
T/RH 状态、仰角、通道频率、地面气象、可选 LWC/cloud flag
```

训练/验证/测试必须按 profile 或日期分组，不能把同一廓线的不同仰角拆到不同集合中。

验收标准：

1. K/V 波段按通道和仰角报告 BT RMSE、bias、最大误差；
2. 在独立逆温、极端湿层和弱云测试集上验证；
3. surrogate OEM 与 MonoRTM OEM 的 posterior 差异必须量化；
4. 超出训练域时触发 OOD 检测并回退 MonoRTM；
5. surrogate 误差必须进入 `S_e`，不能假设为零。

### P2-2：LWC 云天 OEM 分阶段推进

按风险从低到高：

1. synthetic 弱液云：21d `T+RH+LWC`，固定云层位置；
2. synthetic 多云层：改变云底、云顶、LWC 峰值和层厚；
3. cloud-dependent `S_e`：比较 K 波段膨胀、通道剔除和显式 LWC 三种策略；
4. 具备条件后再评估 PAMTRA/散射前向，不让 PAMTRA 阻塞晴空和弱云主线。

验收指标：

```text
T/RH profile RMSE 与近地层误差
LWC RMSE、bias、非负约束违例率
IWV、CLWP/ICLWC 误差
BT residual、DOFS、AK 和收敛率
云天与晴空的性能退化幅度
```

## 6. 不确定度校准：从附加指标升级为主指标

每个主要实验都要同时输出点估计和不确定度：

```text
RMSE / bias / BT residual / DOFS
posterior standard deviation / PICP / MPIW / CRPS
reliability diagram / posterior covariance calibration
```

推荐顺序：

1. 先用 OEM 的 `S_post` 与真实 profile error 做 coverage 检查；
2. 对 `S_a` 做场景分组和尺度校准；
3. 对 BRNN 使用 ensemble 或分位数回归得到先验不确定度；
4. 比较“仅 BRNN”“BRNN prior”“OEM posterior”三种置信区间。

通过条件：后验区间不能只因为变窄就被判为更好，必须同时满足覆盖率接近目标置信水平且误差幅度合理。

## 8. 论文/项目决策闸门

### 闸门 1：多仰角机制

只有当多仰角 + 筛选相对单仰角在 0--500 m T 结构上有跨样本稳定收益，才进入最小高频通道集设计。否则把资源集中到协方差、先验和云天建模。

### 闸门 2：NN/OEM 混合

只有当 BRNN prior + OEM posterior 在统一观测/前向链路下优于 ERA5 prior + OEM，并且 posterior uncertainty 得到校准，才把 BRNN+OEM 作为主论文路线。

### 闸门 3：surrogate

只有当 surrogate OEM 与 MonoRTM OEM 的后验差异可接受、极端样本不失控、且有 MonoRTM 回退机制，才允许用于 n=1000 以上的大样本实验。

### 闸门 4：硬件

只有在算法实验已证明现有频段无法替代高频/多角度的边际信息后，才进入旋转扫描和 220 GHz 以上硬件论证。

## 10. 给师兄/导师的阶段性汇报口径

目前 BRNN v4 已达到 T=1.2639 K、RH=7.759% 的统计反演精度；MonoRTM self-consistent OEM n=100 已达到 T 2.4976->2.2463 K、RH 7.1459->6.7107%、BT 4.9891->0.6090 K，收敛率 99%，DOFS 约 2.21。结合旋转多角度辐射计论文，下一阶段先在现有 14 通道 MonoRTM 平台上验证多仰角和几何通道筛选的机制增益，再处理 MP-3000A/HATPRO 通道桥接，将 BRNN 作为 OEM 的先验和协方差来源；随后推进 NN surrogate、云天 T/RH/LWC 联合反演和不确定度校准。当前不把高频硬件复现作为第一优先级。
