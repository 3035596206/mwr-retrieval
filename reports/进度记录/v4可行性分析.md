# BRNN v4 训练样本可靠性分析

> 撰写日期：2026-06-12 | 更新：2026-06-16

## 问题背景

v4 模型采用 MP-3000A 实测亮温 (Obs_BT) 作为输入、ERA5 再分析廓线作为输出目标（"真值"），在测试集上取得 T RMSE = 1.26 K、RH RMSE = 7.76% 的精度。一个自然的问题是：**训练样本的可靠性从何而来？ERA5 廓线凭什么能充当 "真值"？如果不是真值，模型学到的是什么？**

## 训练样本的双重来源

v4 的 15,838 个训练样本，每个包含两个独立来源的数据：

| 角色 | 数据 | 来源 | 性质 |
|------|------|------|------|
| 输入 | 22ch Obs_BT | MP-3000A 微波辐射计实测 | 物理测量，含仪器噪声和大气信号 |
| 标签 | T(z), RH(z) 廓线 | ERA5 再分析 | 同化分析场，不含仪器噪声 |

**关键区分**：输入和标签来自两个不同的测量系统。输入包含真实的仪器特性和大气-云相互作用，标签由动力-统计最优估计给出。模型学习的是两个系统之间的**条件映射关系**，而非简单复制其中一个。

## ERA5 廓线为什么能作为训练目标

### 1. ERA5 的物理基础：4D-Var 资料同化

ERA5 不是单纯的插值或外推——它是 ECMWF 全球数值天气预报系统通过 **四维变分资料同化 (4D-Var)** 产生的最优化分析场。

```
全球观测网络 ──────────────────────────────────────────────┐
│                                                         │
├── 卫星辐射率（IASI, CrIS, ATMS, AMSU-A, AIRS 等）        │
│   每天数亿次观测，覆盖全球 0-60 km                           │
│                                                         │
├── 探空资料（全球 ~900 站，00Z/12Z）                        │
│   T, RH, u, v 垂直廓线                                    │
│                                                         │
├── 地面站/船舶/浮标（~15,000 站）                            │
│   2m T, 2m RH, Ps, 10m 风                                 │
│                                                         │
├── 飞机报（AMDAR, ~3,000 架/天）                            │
│   航线上的 T, u, v 廓线                                    │
│                                                         │
└── 其他：GPS 掩星、散射计风场、云导风等                       │
                                                         │
                    ▼                                    │
          4D-Var 同化系统                                   │
    · 12 小时时间窗口（09-21Z, 21-09Z）                      │
    · 全球 T799 谱三角截断（~31 km）                          │
    · 137 个混合坐标垂直层（地表 ~ 0.01 hPa）                  │
    · 目标函数：背景场偏差 + 观测偏差 + 物理约束              │
    · 通过切线性和伴随模式迭代求解                             │
                    │                                       │
                    ▼                                       │
          ERA5 分析场 ───────────────────────────────────────┘
  T, q, u, v, ω, O₃ 在全球 31 km 网格 137 层上
```

### 2. 为什么同化分析场优于单站探空

| 比较维度 | 单站探空 | ERA5 分析场 |
|----------|---------|------------|
| 水平信息源 | 1 个气球轨迹（漂移 ~100-200 km） | 全球所有可用观测的加权最优融合 |
| 垂直信息源 | 传感器原位测量 | 探空 + 卫星辐射率的垂直约束 |
| 时间分辨率 | 2 次/天 (00Z, 12Z) | 1 次/小时 |
| 系统偏差 | Vaisala RS41 夜间辐射冷却偏差、RH 高层干偏差 | 偏差订正后的卫星辐射率 + 交叉验证 |
| 物理一致性 | 无 | 模式动力方程约束（质量、动量、能量守恒） |
| 与辐射计匹配站点的样本量 | ~250 条（5 个月） | 20,142 次观测的对齐覆盖 |

**天津站 2023-11至2024-03 的实际情况**：最近的常规探空站在北京南郊（~100 km），每天仅 00Z 和 12Z 两次。过滤降水污染的观测后，可匹配的独立样本仅 ~250 条——远不足以训练 256 单元 × 2 层的 BRNN。ERA5 每小时一个分析时次，与辐射计 24h 连续观测完美对齐，产生了 20,142 个配对样本。

### 3. 4D-Var 对微波辐射计的约束质量

在 4D-Var 系统中，**温度廓线的主要约束来自卫星微波和红外探测仪**——尤其是 AMSU-A（微波温度计）和 IASI（红外高光谱干涉仪）在全球提供覆盖 0-45 km 的辐射率廓线，信息密度和垂直分辨率远超单一探空站。**湿度廓线的主要约束来自微波水汽通道（AMSU-B、MHS、ATMS 183 GHz 通道）和红外水汽通道**，在 5 km 以下尤其敏感。

特别地：AMSU-A 的 50-58 GHz 通道组与 MP-3000A 的 V 波段（51-59 GHz）在物理上观测的是完全相同的 O₂ 吸收带。它们对温度廓线的加权函数峰值高度和宽度高度一致。这意味着 **ERA5 分析中被同化的 AMSU-A 辐射率，在物理意义上和 MP-3000A 看到的是同一类信息**。4D-Var 的作用就是从这些全球分布的辐射率观测中反推出三维温度场，再插值到天津站——这个过程是被大量独立观测约束的，不是自由外推。

因此，ERA5 在天津站的温度廓线具有高度可靠性。

## v3 实验提供的反面证据

v3 是最直接证明 ERA5 廓线与其匹配的实测亮温之间存在**物理一致性**的实验：

```
                         Sim_BT 测试     Obs_BT 测试
Sim_BT 训练 (v3)         0.72 K/5.08%    2.65 K/12.0%   ← 退化 3.7×
Obs_BT 训练 (v4)         —               1.26 K/7.76%   ← 最优
```

v3 用 MonoRTM 模拟亮温训练，在 Obs_BT 上测试时退化 3.7 倍——说明模型看到的"理论亮温"和实测的"真实亮温"之间存在显著不一致。v4 直接在 Obs_BT 上训练，反而取得最优精度。这个对比说明：

1. **MonoRTM 的 Sim_BT 无法完整描述实际大气辐射传输**：它未包含云的微波发射-散射效应、仪器定标漂移、实际水汽连续吸收谱与标准模型的偏差
2. **但这些偏差在 Obs_BT 中被 ERA5 廓线的系统性结构间接吸收**：因为 ERA5 廓线本身是由包含了这些真实复杂性的卫星辐射率同化产生的
3. **直接用 Obs_BT 训练是在"绕过"而不是"解决"辐射传输模拟的不完整性问题**——这对于业务反演是完全可行的策略

## 行业对标：这是标准做法

在地基多通道微波辐射计廓线反演领域，**用分析/再分析廓线作为训练目标是广泛采纳的行业实践**，而非本项目独创：

| 研究 | 训练标签 | 模型 |
|------|---------|------|
| Cadeddu et al. (2013, JGR) | ECMWF 分析场 | 回归 + 神经网络 |
| Löhnert et al. (2009, JAMC) | 无线电探空 | 最优估计 (1D-Var) |
| Chakraborty & Maitra (2016, IEEE TGRS) | 探空 + ERA-Interim | 神经网络 |
| Araki et al. (2015, JMSJ) | 探空 + 再分析 | 多元回归 |
| 本项目 (v4) | ERA5 再分析 | BRNN (6 model ensemble) |

## 已知局限与改进方向

1. **标签不完全等于真值**：ERA5 分析场在天津地区的误差，尤其在云降水条件下和夜间逆温条件下的系统性偏差，会传导到模型权重。需要将这种"标签噪声"与模型预测误差区分开。

2. **廓线分组 vs 时间独立**：当前的廓线分组划分确保同一大气状态的多次观测不在训练和测试间泄露，但未测试模型对**未见过季节**（如夏季 7-8 月）的泛化能力——训练数据仅覆盖 11月-3月。

3. **MonoRTM 两阶段训练（v6 路线增强版）**：在 Era5 气压层数据量足够后，用 MonoRTM 批量生成约 30 万条 Sim_BT→廓线配对，第一阶段的预训练建立物理骨架，第二阶段用 Obs_BT 微调，可望同时获得 Sim_BT 的物理一致性和 Obs_BT 的真实大气代表性。

4. **引入独立验证数据**：可收集天津或北京站的实际探空资料作为独立测试集，对模型的绝对精度进行外部交叉验证（而不仅是相对于 ERA5 的内部测试）。
