### 4.2 四条 NN + OEM 技术路线

根据深度调研报告，NN 与 OEM 结合可以分为四类。本项目的适配度如下：

| 路线 | 方法 | 本项目优先级 | 当前策略 |
|------|------|--------------|----------|
| NN 作为先验或先验协方差 | NN 输出 `x_a` 或 `S_a` | 最高 | 使用 BRNN v4 / v4 residual 构造 `S_a` |
| NN 替代前向模型 | NN surrogate 近似 `H(x)` | 高 | 用 MonoRTM 批量样本训练 surrogate |
| NN 误差建模与后处理 | NN 修正 OEM 残差或校准不确定度 | 中高 | 用于 forward mismatch 和 posterior calibration |
| Unrolled / DeepOE | 将 OEM 迭代展开为可训练网络 | 长线 | 稳定 OEM 基线后再推进 |

当前优先级：

```text
P0: 稳定 MonoRTM OEM baseline
P1: BRNN / v4-derived S_a 作为 OEM 先验协方差
P1: MonoRTM surrogate forward model，用 NN 加速 H(x)
P2: 不确定度校准，ensemble / MC dropout / QRNN
P3: DeepOE / unrolled OEM，作为论文级长线方向
```

## 5. 核心方法框架

### 5.1 OEM 目标函数

OEM 使用背景场和观测共同约束状态向量：

```text
J(x) =
(x - x_a)^T S_a^-1 (x - x_a)
+
(y - H(x))^T S_e^-1 (y - H(x))
```

其中：

| 符号 | 含义 | 当前实现 |
|------|------|----------|
| `x` | 状态向量 | 14d T7+RH7，后续 21d T+RH+LWC |
| `x_a` | 背景场 | ERA5 扰动，后续 BRNN first guess |
| `S_a` | 背景误差协方差 | 指数相关 / v4-derived |
| `y` | 观测亮温 | synthetic BT / MonoRTM BT / 后续 Obs_BT |
| `H(x)` | 前向模型 | simple RTM / MonoRTM |
| `S_e` | 观测误差协方差 | K-band 1.5K, V-band 0.5K，后续 cloud-dependent |

### 5.4 NN surrogate 前向模型

深度调研报告建议可用 NN 替代前向模型以加速 OEM。本项目建议优先做 residual surrogate：

```text
BT_mono ≈ BT_simple + NN(profile)
```

原因：

```text
1. Simple RTM 与 MonoRTM 差异显著，直接学习 residual 更容易解释。
2. MonoRTM 单廓线含 Jacobian 约 7s，批量 OEM 会有计算压力。
3. surrogate 可用于快速筛选、敏感性分析和大样本实验。
```

候选模型：

```text
MLP
1D-CNN
Residual MLP
Ensemble surrogate
```

验收标准：

```text
1. K/V band BT surrogate RMSE 接近或低于观测误差量级。
2. surrogate OEM 后验接近 MonoRTM OEM。
3. 推理速度显著快于 MonoRTM。
4. surrogate error 能并入 S_e 或单独建模。
```

### 5.5 不确定度与校准

后续评估不应只看 RMSE，还要看不确定度是否可信。

新增指标：

```text
PICP: prediction interval coverage probability
MPIW: mean prediction interval width
CRPS: continuous ranked probability score
reliability diagram
posterior covariance calibration
```

候选方法：

```text
1. Ensemble
2. MC Dropout
3. QRNN 分位数回归
4. posterior covariance calibration
```

目标：

```text
让模型不仅知道“预测是多少”，还知道“自己有多不确定”。
```

## 6. 当前阻塞与风险

### 6.1 BRNN + OEM 混合仍被阻塞

阻塞项：

```text
1. 缺 MP-3000A Obs_BT 原始观测数据
2. BRNN v4 是 MP-3000A 训练体系
3. 当前 OEM/MonoRTM 管线是 HATPRO 14ch
4. v4 与 HATPRO 14ch 管线存在通道与特征不一致
```

短期策略：

```text
不强行做 BRNN v4 + OEM；
先做 ERA5/MonoRTM self-consistent OEM；
再设计 MP-3000A 通道映射或重训统一模型。
```

---

### 6.2 MonoRTM 计算成本

当前估计：

```text
MonoRTM 单廓线含 Jacobian 约 7s
n=100 可接受
n=1000 或更大需要优化或 surrogate
```

应对：

```text
1. 先完成 n=100 / n=744 级别实验
2. 缓存 H(x) 与 Jacobian
3. 降低状态维度
4. 训练 NN surrogate
5. 样本级并行
```

---

### 6.3 NN surrogate 外推风险

风险：

```text
NN surrogate 若训练样本覆盖不足，可能在极端温湿廓线、云天、逆温条件下外推失败。
```

应对：

```text
1. 保留独立测试集和极端样本测试集
2. surrogate error 必须低于或并入 S_e
3. 对超出训练范围的样本回退 MonoRTM
4. 不直接用 surrogate 结果替代物理结论
```

---

### 6.4 不确定度低估

风险：

```text
纯 NN 往往过度自信，直接把 NN uncertainty 当作 OEM 协方差会有风险。
```

应对：

```text
1. ensemble / MC dropout / QRNN
2. PICP / CRPS / reliability diagram
3. 后验协方差校准
4. 与真实误差分布对比
```
