## 0. 给 AI 助手的总览

本项目是一个**地基微波辐射计（MWR）大气温湿廓线反演系统**，包含两条技术路线：

| 路线 | 方法 | 核心指标 |
|------|------|----------|
| **BRNN v4** | 贝叶斯正则化神经网络统计反演 | T=1.26K, RH=7.76% |
| **MonoRTM OEM** | 最优估计物理反演（self-consistent） | T=2.64→2.02K, RH=6.49→6.20%, BT=5.03→0.61K |

**复现目标**：
1. BRNN v4 训练 → 得到 T≈1.26K / RH≈7.76%
2. MonoRTM OEM n=100 baseline → 得到 T=2.64→2.02K / BT=5.03→0.61K / 收敛率≥95%

**你需要准备的**：
- 一台 Windows 10/11 机器，已安装 WSL2 + Ubuntu-24.04
- Python 3.12 虚拟环境（项目自带 `.venv-wsl`）
- Git + SSH key 已配置 GitHub 访问

## 7. 常见问题

### Q1: `Permission denied (publickey)`
将 `~/.ssh/id_ed25519.pub` 添加到 GitHub Settings → SSH Keys。

### Q2: `Exec format error: bin/monortm`
`bin/monortm` 是 macOS 二进制，Linux/WSL 请用 `bin/monortm_linux`。仓库已配置自动检测。

### Q3: `ModuleNotFoundError: No module named 'torch'`
请确保激活了虚拟环境：`source .venv-wsl/bin/activate`

### Q4: MonoRTM 运行很慢
正常。每条廓线约 5 秒（含 Jacobian 有限差分计算），n=100 约 8 分钟。如需加速，可先用 n=20 验证链路。

### Q5: OSError: TAPE3 not found
检查 `data/TAPE3/TAPE3_bin` 是否存在（235,912 bytes）。若缺失，需从原始 ASCII TAPE3 转换：`python convert_tape3.py`
