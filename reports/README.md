# MWR 廓线反演项目 — 报告与文档中心

本目录独立于代码库，用于定期维护和更新项目文档、进度记录和分析图表。

## 目录结构

```
reports/
├── README.md                  ← 本文件：更新规则与索引
├── 进度记录/                  ← 工作日志、缺陷追踪
│   ├── 工作进度6.6.md         # 2026-06-06 进度（数据诊断、管线适配、v1-v4初版）
│   ├── 工作进度6.8.md         # 2026-06-08 进度（TAPE3下载、MonoRTM调试）
│   ├── 工作进度6.xx.md        # 后续进度（按日期命名）
│   └── 未订正缺陷.md          # 数据缺陷分类（5个缺陷，有严重度/状态/修复方向）
├── 技术报告/                  ← 正式报告（Word + PDF）
│   ├── BRNN_v4_技术报告.docx
│   ├── BRNN_v4_技术报告.pdf
│   └── 专业实践报告.docx
└── 分析图表/                  ← 关键可视化结果
    ├── error_profiles.png     # 分层误差廓线
    ├── sample_T_profiles.png  # 最佳/最差T廓线
    ├── sample_RH_profiles.png # 最佳/最差RH廓线
    └── scatter_density.png    # 散点密度图
```

## 更新规则

### 进度记录
- 每次工作结束后，新建或追加 `工作进度YYYYMMDD.md`：
  - 本次工作概要
  - 关键产出文件
  - 遇到的问题与解决方案
  - 下一阶段的断点信息（激活环境、数据路径、待执行命令）
- `未订正缺陷.md`：新发现的缺陷随时添加；已修复的标注 ✅ 和修复版本号

### 技术报告
- 每个版本迭代完成后，更新技术报告（覆盖旧版或另存新版）
- 保留历史版本以便追溯（如 `BRNN_v4_技术报告.docx`、`BRNN_v5_技术报告.docx`）
- 报告生成脚本：`generate_report.py`

### 分析图表
- 模型评估后更新最新的误差分析图
- 图片命名稳定（不改变文件名），方便外部引用
- 生成脚本：`retrieve_and_plot.py`、`generate_report.py`

### Git 提交
```bash
cd /Users/ink/test/mwr_retrieval
# 更新报告后
git add reports/ && git commit -m "报告更新: [简述]"
git push origin main
```
